## 🌐 Deploying to GitHub Pages (`abhitvg.github.io` or `abhitvg`)

### 1. Initialize Git & Add Remote
If you have created a repository on GitHub named `abhitvg` or `abhitvg.github.io`:

```bash
cd /Users/abhisheksingh/.gemini/antigravity-ide/scratch/abhitvg

git init -b main
git add .
git commit -m "feat: complete modern portfolio website for Abhishek Singh (abhitvg)"

# Replace with your actual GitHub repository URL:
git remote add origin https://github.com/Abhitvg/abhitvg.git
git push -u origin main
```

### 2. Enable GitHub Pages
1. Go to your repository on GitHub: `https://github.com/Abhitvg/abhitvg`
2. Navigate to **Settings** > **Pages**
3. Under **Branch**, select `main` and `/ (root)`, then click **Save**.
4. Within 1-2 minutes, your website will be live at `https://abhitvg.github.io/abhitvg` (or `https://abhitvg.github.io` if the repo name is `abhitvg.github.io`).
